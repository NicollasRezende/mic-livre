# Segurança e privacidade

O transporte desta versão é destinado a uma rede local confiável. Áudio PCM e código de conexão não são criptografados. A descoberta informa nome do computador e porta; não divulga o código. Não exponha as portas na internet.

O aplicativo não usa conta, nuvem, anúncios ou telemetria. Mute envia silêncio e mantém a captura ativa; use Parar para liberar o microfone. Gravação no PC só ocorre se você usar explicitamente `--output`.

Para relatar uma falha que ainda não deve ser divulgada, use **Security → Report a vulnerability** no GitHub, se a opção estiver habilitada. Caso não esteja, abra uma issue pedindo um canal reservado, sem publicar o exploit, credenciais ou dados pessoais. Não envie gravações privadas para issues.

A manutenção acontece por contribuições voluntárias; não há SLA ou promessa de suporte a todos os aparelhos. A versão inicial foi testada em Linux Mint com PipeWire e um Moto G34. A lista de limitações verificadas está no README.
